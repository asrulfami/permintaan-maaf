BEBBYKU — MASONRY COLLAGE APOLOGY WEBSITE

Struktur folder ini sudah disesuaikan dengan project Bebbyku:
- index.html
- css/style.css
- js/script.js
- assets/audio/keepme.mp3
- assets/images/1.jpeg sampai 10.jpeg

CARA PAKAI
1. Ekstrak ZIP.
2. Salin file index.html, folder css, folder js, dan folder assets ke project Bebbyku.
3. Jika Windows/VS Code meminta konfirmasi, pilih Replace untuk index.html, css/style.css, dan js/script.js.
4. Jika foto 1.jpeg sampai 10.jpeg milikmu sudah benar di assets/images, kamu boleh mempertahankan foto yang sudah ada dan tidak perlu menyalin folder images dari ZIP.
5. Pastikan assets/audio/keepme.mp3 tersedia.
6. Buka index.html dengan Live Server.

Catatan:
- File audio diputar setelah tombol pembuka diklik, sesuai aturan autoplay browser.
- File monokrom.mp3 milik project lama tidak termasuk dan tidak perlu dihapus.
- Semua path menggunakan path relatif agar siap untuk GitHub Pages.
